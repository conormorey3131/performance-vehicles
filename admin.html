Your GitHub publishing key authorises stock updates. It is held in memory for this tab and is never saved to the website or this device.

First time? Set up publishing access
  1. Open GitHub’s publishing-key setup ↗ and sign in.
  2. Choose the conormorey3131 resource owner and Only select repositories. Select performance-vehicles.
  3. Give repository Contents: Read and write permission. Keep a short expiry date.
  4. Generate the key, copy it and paste it above. You can revoke it in GitHub at any time.

Use an account with write access to this repository. Please never send your publishing key in chat or email.
