# Performance Vehicles

Website design preview for Performance Vehicles, prepared for review.

The static site includes six showcase cars, search filters, saved favourites, photo galleries and an email enquiry composer. Contact information is sample content; vehicle availability and specifications require confirmation.

Published preview: https://conormorey3131.github.io/performance-vehicles/

The purchased domain performancevehicles.ie is awaiting connection to production hosting.

## Files

- `index.html`: page content
- `styles.css`: responsive design
- `inventory.js`: vehicle collection
- `app.js`: filters, galleries, favourites and enquiries
- `assets/`: website images
